# copy egress/allowlist.txt, created from this template on first `make` run.
# Edit allowlist.txt for machine-local needs without touching git; changes
# that every developer needs belong in this template.

#   example.com   matches exactly example.com
#   .example.com  matches example.com AND all subdomains
#
# Keep this list MINIMAL. Every entry is a potential exfiltration channel.
# In particular: git remote hosts (github.com, gitlab.com, ...) must NEVER
# be added here — pushing is a host-only operation by design, and this list
# is the second line of defense after the git wrapper.
#
# WARNING: widening this list also weakens the reasoning that makes the
# read-only signing-key mount acceptable (see README.md, "Signing key
# exfiltration trade-off").
